# لندینگ فارسی کلینیک (Next.js 14)

یک قالب لندینگ پیج فارسی، RTL، سریع و سئو‌شده برای کسب‌وکارهای کوچک. نمونه‌ی پیاده‌سازی با یک کلینیک دندانپزشکی فرضی؛ با عوض کردن یک فایل برای هر مشتری قابل استفاده است.

## مسئله‌ای که حل می‌کند

کسب‌وکارهای کوچک معمولاً سایتی کند، غیرریسپانسیو و بدون سئو دارند و مشتری از دست می‌دهند. این پروژه یک سایت سریع، قابل‌دسترس و آماده‌ی گوگل با فرم تماس واقعی ارائه می‌دهد.

## ویژگی‌ها

- RTL کامل با فونت وزیرمتن (از `next/font/google`؛ فونت در زمان build دانلود و self-host می‌شود، بدون درخواست runtime به گوگل)
- سئو: metadata، Open Graph، `sitemap.xml`، `robots.txt` و داده ساختاریافته JSON-LD
- فرم تماس واقعی: اعتبارسنجی با Zod در کلاینت و سرور، پشتیبانی از ارقام فارسی در شماره موبایل، honeypot ضد اسپم، rate limit و ارسال ایمیل با Resend
- دسترسی‌پذیری: لینک «رفتن به محتوای اصلی»، `aria` در منو و فرم، پشتیبانی از `prefers-reduced-motion`
- تمام محتوا در `lib/site.ts`؛ برای مشتری جدید فقط همین فایل را ویرایش کنید
- بخش نظرات فقط وقتی نمایش داده می‌شود که نظر واقعی اضافه کنید

## اجرا

```bash
npm install
cp .env.example .env.local
npm run dev
```

سایت روی `http://localhost:3000` بالا می‌آید.

## تنظیم ایمیل فرم تماس

در `.env.local` مقادیر `RESEND_API_KEY` و `CONTACT_TO_EMAIL` را بگذارید. بدون آن‌ها فرم در حالت دمو کار می‌کند و پیام فقط در لاگ سرور ثبت می‌شود.

## دیپلوی

1. پروژه را روی GitHub بگذارید.
2. در Vercel پروژه را import کنید.
3. متغیرهای `.env.example` را در تنظیمات Vercel اضافه کنید (حتماً `NEXT_PUBLIC_SITE_URL` را با دامنه واقعی).

## ساختار

```
app/
  api/contact/route.ts   API فرم تماس
  layout.tsx             RTL، فونت، metadata
  page.tsx               ترکیب بخش‌ها + JSON-LD
  sitemap.ts, robots.ts
components/              Header, Hero, Services, Process, Faq, Contact...
lib/
  site.ts                محتوای سایت (اینجا را عوض کنید)
  validation.ts          schema مشترک کلاینت و سرور
```

## نکته

محدودیت نرخ درخواست در حافظه است و روی سرورلس بین instanceها مشترک نیست. برای پروژه‌ی جدی‌تر از Upstash Redis استفاده کنید.
